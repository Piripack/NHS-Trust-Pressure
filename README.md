# NHS Trust Pressure

This repository contains the public-facing material for an NHS trust pressure project using public operational data.

The project looks at three practical questions:
- which trusts may face the worst severe pressure next month
- whether that pressure looks mainly driven by demand, flow, or capacity
- which simple operational lever appears most promising

## Main Result

Across 13 month-to-next-month tests, the 10% of trusts flagged as highest risk contained about 31% of the severe pressure seen in the following month.

The best simpler comparison method captured about 25%.
