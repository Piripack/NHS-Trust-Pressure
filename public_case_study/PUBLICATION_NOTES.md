# Publication Notes

This folder is designed to be the public-facing version of the project.

## Recommended GitHub Positioning

Describe it as:

`A validated trust-level early-warning and prioritisation tool for severe pressure, with driver decomposition and simple intervention simulation.`

## Recommended Repo Behaviour

Publish:
- methodology
- results
- selected output samples
- polished visuals

Do not publish:
- full implementation
- end-to-end private scoring code
- internal working files

## Why This Approach Works

For future research/data scientist roles or future partnerships, the important thing is showing:
- a real problem
- a credible method
- a validation framework
- operational relevance
- an ability to translate analysis into action

That can be shown without open-sourcing the private implementation.
