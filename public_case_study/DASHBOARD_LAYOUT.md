# Dashboard Layout

If this case study is published on GitHub, the best presentation is a static one-page dashboard image or PDF.

## Recommended Layout

### Top Row

- Title
- one-sentence project description
- three headline metrics:
  - mean top-decile capture
  - improvement vs best baseline
  - windows beating baseline

### Middle Left

Baseline comparison chart:
- final score
- last-month 12h wait rate baseline
- rolling 3-month baseline

### Middle Right

Calibration chart:
- low
- medium
- high

Use average next-month 12h waits on the y-axis.

### Bottom Left

Latest-month top 10 trust table:
- trust
- risk band
- dominant driver
- action type
- best lever

### Bottom Right

Scenario comparison for selected example trusts:
- current score
- score under `+5% discharges`
- score under `+5% available beds`
- score under `-5% admissions`

## Recommended File

Export one static visual and place it here later:
- `assets/dashboard.png`

That is enough. A live app is optional and not necessary for a GitHub case study.
